# プライバシーポリシー

アプリ「GlobalBoard」におけるユーザー情報の取り扱いについて、以下のとおり定めます。

## 1. 取得する情報
当アプリでは、サービスの提供および改善のため、以下の情報を取得・利用する場合があります。
- アプリ内課金に関する情報（StoreKit を通じたトランザクション情報）
- ユーザーが投稿・送信したコンテンツ

## 2. 利用目的
取得した情報は、以下の目的で利用します。
- 掲載機能および有料プランの提供・管理
- お問い合わせへの対応およびサービスの改善

## 3. 第三者提供
法令に基づく場合を除き、事前同意を得ずにユーザーの個人情報を第三者に提供することはありません。
